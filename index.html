Level 1 — Beginner The Grid

Learn the basics.

  1. Interface

    Ribbon tabs (Home/Insert/Data), Name Box, Formula Bar, sheet tabs, and the status bar — select some numbers and it shows the Sum instantly.

  2. Editing

    Numbers align right, text left. Enter moves down · Tab right · F2 edits · Delete clears · Alt+Enter adds a line inside a cell.

  3. Navigation

    Ctrl+→ jumps to the edge of data · Ctrl+Shift+→ selects to it · Ctrl+A selects all · Ctrl+Home goes to A1.

  4. Formatting

    Bold, fill colors, borders, column widths (double-click the border to autofit). Number formats via Ctrl+1: %, currency, dates. Formatting never changes the value.

  5. Formulas

    Type =, then click cells. Prefer references over typed numbers — results update automatically.

    fx =B2*C2   ' price × qty

  6. Functions

    Plus Alt+= = AutoSum. Click a chip to copy:

    =SUM(B2:B10)=AVERAGE(B2:B10)=COUNT(B2:B10)=COUNTA(A2:A10)=MAX(B2:B10)=MIN(B2:B10)

  7. AutoFill

    Drag the corner square to copy down. It continues patterns: 1,2 → 3,4… · Jan → Feb… · =B2*C2 → =B3*C3…

GOAL — 5 products, price × qty column, dragged formulas, AutoSum total. Ten minutes, tops.

Level 2 — Foundational Daily Tools

Everyday essentials.

  1. References Most Important

    Lock cells that must stay put when a formula is dragged. Press F4 to cycle A1 → $A$1 → A$1 → $A1.

    fx =B2*$H$1   ' B2 moves down; tax rate H1 stays

  2. Sorting

    Use Ctrl+Shift+L for filter buttons. Data → Sort (multi-level). Header dropdowns filter by value, color, or conditions like “Above Average”.

  3. Freezing

    View → Freeze Top Row. Select B2 first to lock row 1 and column A together.

  4. Conditions

    IF for logic; the *IF(S) family for conditional math:

    fx =IF(B2>=60,"Pass","Fail")
    =SUMIF(A:A,"West",B:B)=COUNTIF(C:C,">=1000")=SUMIFS(C:C,A:A,"West",B:B,">500")

  5. Text

    =LEFT(A2,3)=RIGHT(A2,4)=LEN(A2)=TRIM(A2)=PROPER(A2)=A2&" "&B2=TODAY()=TEXT(A2,"mmm yyyy")=DATEDIF(A2,B2,"d")=EOMONTH(A2,0)

    Dates are numbers underneath: =A2+7 gives next week, =B2-A2 gives days between.

  6. Highlighting

    Home → Conditional Formatting: highlight rules, data bars, color scales. A formula rule like =$B2="Overdue" highlights entire rows.

  7. Charts

    Select data including headers → Alt+F1. Column = compare, line = trend, pie = few slices, scatter = correlation. Use the chart's + button for titles and labels.

  8. Dropdowns

    Data → Data Validation → List, e.g. Active,On Hold,Closed. Add input messages and error alerts too.

GOAL — a personal budget: months across the top, a % of income column (use $!), data bars, one chart, frozen header.

Level 3 — Intermediate Power User

Work with data.

  1. VLOOKUP

    Finds a value down the first column and returns from column n. Almost always use FALSE (exact match).

    fx =VLOOKUP(A2, Products!$A$2:$C$100, 3, FALSE)

  2. INDEX+MATCH

    The flexible classic — looks any direction and survives inserted columns:

    fx =INDEX(C2:C100, MATCH(A2, A2:A100, 0))

  3. IFERROR

    Show your own message instead of #N/A when a lookup fails:

    fx =IFERROR(VLOOKUP(A2,$H$2:$J$50,2,FALSE), "Not found")

  4. Tables Superpower

    Ctrl+T turns data into a Table: auto-filters, auto-expanding ranges, one formula fills the whole column, and readable references:

    fx =SUMIFS(Sales[Amount], Sales[Region], "West")

  5. Names

    Select a cell, type TaxRate in the Name Box, then write =B2*TaxRate. Manage them under Formulas → Name Manager.

  6. PivotTables Core Skill

    Insert → PivotTable. Drag Region → Rows, Amount → Values, Month → Columns. Then: Value Field Settings → % of Grand Total · right-click dates → Group · add a Slicer · refresh with Alt+F5.

  7. Logic

    =IFS(B2>=90,"A",B2>=80,"B",TRUE,"F")=IF(AND(B2>1000,C2="Gold"),"Bonus","")=SWITCH(A2,"N","North","S","South","?")

  8. Cleanup

    Flash Fill Ctrl+E (type one example) · Text to Columns · Remove Duplicates · Ctrl+G → Special → Blanks, then =A2 and Ctrl+Enter to fill every gap at once.

  9. Printing

    Set a Print Area · “Rows to repeat at top” = $1:$1 · Fit all columns on one page · Export to PDF.

GOAL — a sales table: a SUMIFS rep leaderboard, a region × month pivot with slicer, and a category column pulled in by lookup.

Level 4 — Advanced Modern Excel

Modern power tools.

  1. XLOOKUP

    Looks any direction, exact match by default, built-in not-found message, and can return multiple columns:

    fx =XLOOKUP(A2, Products[ID], Products[Price], "Not found")

  2. Arrays

    One formula fills many cells. Reference an entire spilled range with =E2#.

    =UNIQUE(A2:A500)=SORT(A2:C500,3,-1)=FILTER(A2:C500,B2:B500>1000,"none")=SEQUENCE(10)=TEXTSPLIT(A2,", ")

  3. LET+LAMBDA

    Readable formulas, plus custom functions with no VBA — just name it in the Name Manager:

    fx =LET(x, A2*B2, tax, x*0.08, x+tax)
    fx =LAMBDA(a,b, SQRT(a^2+b^2))

  4. PowerQuery Biggest Time-Saver

    Data → Get Data: import, clean, and combine with recorded, replayable steps. “From Folder” merges monthly CSVs, Merge performs real joins, and Unpivot fixes wide data. Next month: one Refresh All.

  5. PowerPivot

    Millions of rows, multiple related tables, and measures:

    fx Sales LY := CALCULATE([Total Sales], SAMEPERIODLASTYEAR(Calendar[Date]))

  6. Classics

    =SUMPRODUCT((A2:A100="West")*(B2:B100>1000)*C2:C100)=OFFSET(A1,2,0,5,1)=INDIRECT("'"&A2&"'!B5")

    OFFSET and INDIRECT are volatile — prefer INDEX and Tables on large sheets.

GOAL — combine two CSVs with Power Query, clean them, load as a Table, and build a live FILTER report.

Level 5 — Expert Automation

Automate everything.

  1. Macros

    Enable the Developer tab (File → Options → Customize Ribbon). Developer → Record Macro → do the steps → Stop. Always save as .xlsm.

  2. VBA

    Alt+F11 opens the editor. F8 steps line by line, F9 toggles breakpoints. Core objects: Range Cells Worksheets ThisWorkbook.

    fx Rows(1).Font.Bold = True : Columns("C").AutoFit

  3. What-If

    Goal Seek = work a formula backward to a target · Data Tables = sensitivity grids · Scenario Manager = saved bundles of inputs · Solver = optimization with constraints.

  4. Dashboards

    Three layers: Data (a Power Query-fed Table) → Calc (hidden pivots and arrays) → View (KPI cards, PivotCharts, slicers wired to every pivot via Report Connections). Hide gridlines and protect the sheet.

  5. Habits

    Separate inputs / calculations / outputs (color the tabs) · audit with Trace Precedents arrows · protect formula cells · OneDrive version history + co-authoring · use .xlsb for huge files · switch to manual calc (refresh with F9) when heavy.

GOAL — a one-click monthly report: drop CSVs in a folder → Refresh All → dashboard updates → formatting macro replays.
